1.2 ALL GROUP STATUSES
--------------------------------------------------------------------------------

SETUP PHASE:
  FORMING                    - Pembentukan kelompok, anggota belum cukup
  FORMING_SOLO               - Mencari solo partner
  READY_FOR_BIDDING          - Siap bidding judul
  WAITING_SUPERVISOR_APPROVAL- Menunggu approval dosen pembimbing
  TITLE_APPROVED             - Judul disetujui, open recruitment
  READY_FOR_FINALIZATION     - Siap finalisasi admin
  KELOMPOK_FINAL             - Kelompok sudah difinalisasi

PDC1 PHASE:
  PDC1_ACTIVE                - PDC1 aktif, bimbingan berjalan
  READY_FOR_SEMPRO           - Siap SEMPRO
  SEMPRO_DONE                - SEMPRO selesai

PDC2 PHASE:
  PDC2_ACTIVE                - PDC2 aktif
  PDC2_READY_FOR_EXPO        - Siap EXPO
  EXPO_REGISTERED            - EXPO terdaftar
  EXPO_DONE                  - EXPO selesai
  PDC2_COMPLETED             - PDC2 selesai, peer review unlocked

FINAL:
  CLOSED                     - Kelompok ditutup
  DISSOLVED                  - Kelompok dibubarkan

1.4 SCHEDULE/EVALUATION STATUS
--------------------------------------------------------------------------------

Schedule Status:
  SCHEDULED          - Jadwal dibuat
  COMPLETED          - Semua evaluasi submitted
  CANCELLED          - Jadwal dibatalkan
  PENDING_APPROVAL   - Menunggu approval admin

Evaluation Status:
  PENDING            - Evaluasi belum disubmit
  SUBMITTED          - Evaluasi sudah disubmit
  PARTIAL            - Sebagian nilai submitted
  COMPLETED          - Semua nilai submitted

================================================================================
                          5. COMPLETE WORKFLOW
================================================================================

--------------------------------------------------------------------------------
FASE 1: KONFIGURASI (ADMIN)
--------------------------------------------------------------------------------

1. Create Assessment Component Templates (Bank Soal)
   └── Components: code, name, description, weight

2. Configure Period Assessment Components
   └── Select templates for each evaluation type per period

3. Configure Grade Weights
   └── PDC1 weights, PDC2 weights

--------------------------------------------------------------------------------
FASE 2: GROUP FINALIZATION → PDC1_ACTIVE
--------------------------------------------------------------------------------

Group reaches READY_FOR_FINALIZATION
    │
    ▼
Admin finalizes group
    │
    ├──► KELOMPOK_FINAL
    │
    └──► PDC1_ACTIVE

Supervisors assigned via supervisions table

--------------------------------------------------------------------------------
FASE 3: SEMPRO (EXAMINER EVALUATION)
--------------------------------------------------------------------------------

1. Admin schedules SEMPRO for group
   └── Creates SeminarSchedule
   └── Auto-generates SeminarEvaluation rows for examiners (status=PENDING)
   └── Status: SCHEDULED

2. Examiners submit evaluations
   └── POST /dosen/sempro/{schedule}/evaluate
   └── Each examiner submits: rubric_json, score, result (PASS/FAIL)
   └── Evaluation status: PENDING → SUBMITTED

3. All evaluations submitted → Auto-transition
   └── Schedule status: COMPLETED
   └── If PASS: Group → SEMPRO_DONE → PDC2_ACTIVE
   └── If FAIL: Group → PDC1_ACTIVE (retry)

--------------------------------------------------------------------------------
FASE 4: BIMBINGAN_SEMPRO (SUPERVISOR EVALUATION)
--------------------------------------------------------------------------------

1. Supervisors view pending evaluations
   └── GET /dosen/supervisor-evaluation/schedules

2. Supervisor gets evaluation form
   └── GET /dosen/supervisor-evaluation/form/{groupId}?type=BIMBINGAN_SEMPRO

3. Supervisor submits scores per student per component
   └── POST /dosen/supervisor-evaluation
       └── evaluation_type: BIMBINGAN_SEMPRO
       └── scores: array of {period_component_id, student_id, score, notes}

4. Check if all bimbingan scores complete
   └── Checks if both supervisors have submitted scores

5. Trigger grade recalculation when complete
   └── GradeCalculationService::recalculateAndNotify()

--------------------------------------------------------------------------------
FASE 5: PDC2_ACTIVE → EXPO (SAME PATTERN)
--------------------------------------------------------------------------------

Group → PDC2_READY_FOR_EXPO
    │
    ▼
Admin schedules EXPO (Similar to SEMPRO scheduling)
    │
    ▼
Examiners submit EXPO evaluations
    └── POST /dosen/expo/{schedule}/evaluate
    │
    ▼
If PASS: Group → EXPO_DONE → PDC2_COMPLETED (peer review unlocked)
    │
    ▼
Supervisors submit BIMBINGAN_EXPO + MILESTONE evaluations
    └── Same supervisor evaluation endpoints

--------------------------------------------------------------------------------
FASE 6: TA DEFENSE
--------------------------------------------------------------------------------

Student registers TA → TA_REGISTERED
    │
    ▼
Admin schedules TA Defense
    └── Creates TaDefenseSchedule
    └── Auto-attaches supervisors via TaDefenseExaminer
    └── Adds external examiners
    └── Auto-generates TaDefenseEvaluation rows (status=PENDING)
    │
    ▼
Examiners submit TA Defense evaluations
    └── POST /dosen/ta-defense/{schedule}/evaluate
    │
    ▼
All submitted → Auto-determine result
    ├── If PASS: TaSubmission → TA_DEFENDED
    ├── If all group members defended: Group → CLOSED
    └── If FAIL: TaSubmission → TA_REVISED
    │
    ▼
Supervisors submit BIMBINGAN_TA evaluations

--------------------------------------------------------------------------------
FASE 7: GRADE CALCULATION
--------------------------------------------------------------------------------

Triggered when all evaluations complete
    │
    ▼
GradeCalculationService::recalculateAndNotify()
    │
    ├── Calculates weighted averages
    │   ├── Per component: score × weight
    │   ├── Per evaluator group: sum(weighted_scores) / sum(weights)
    │   └── Final grade based on PDC1/PDC2 weights
    │
    └── Admin can view summary
        └── GET /admin/assessment-scores/summary
